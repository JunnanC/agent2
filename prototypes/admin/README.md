# 管理端 HTML 交互原型

双击 `index.html`，使用浏览器打开即可，无需安装依赖或启动服务。七个页面通过左侧导航切换，也支持 `#courses`、`#students` 等地址锚点。

原型只使用演示数据，操作保存在页面内存中，刷新即重置，不连接真实后端。账号禁用恢复、课程下架、镜像新增编辑与启停会同步更新操作日志。服务和资源仅查看。

## 页面

- 运行概览：按演示数据计算人数、课程与实例数量，展示节点 CPU 采样、服务健康、资源占用和近期操作。
- 课程与班级：同名不同 ID 的课程，课程详情、学生名单、实验时间及违规下架。
- 学生管理：18 个示例账号、分页、加入课程、账号禁用恢复。
- 教师管理：4 位示例教师、创建的课程、账号禁用恢复，无教师审批。
- 镜像管理：名称、地址、版本、用途、启停，含新增编辑、必填及重复校验、关联课程。
- 服务与资源：6 类服务和2个实验节点，服务详情、资源占用与运行实例，只读。
- 操作日志：操作对象、类型、时间、原因、变更前后配置与筛选。

## 设计记录

产品：教学实验平台的运维管理后台。
性格：克制、准确、可追溯。
世界：实验室仪表、课程名册和节点库存。
重点：节点使用率曲线和服务健康状态，色彩只表达数据与操作。
识别细节：等宽课程 ID 贯穿列表、详情、关联记录和日志。

本次为新建原型，未更改原管理端。原模块的教师资格审核、课程审批、独立班级管理、服务控制与配额编辑不进入新原型。使用同一间距体系、灰白表面、统一线性图标、三层文本颜色、系统中文字体与等宽元数据、统一表格和弹窗，无循环动画及装饰图片。

采用 unslop 设计方法：Damir Sokolovsky（@heydamir），CC BY 4.0，https://heydamir.design/unslop 。辅助使用 design-taste-frontend 的 Framed sheet 方向：浅灰外框、白色工作区、无阴影、下划线标签页。

## 验证

`node prototypes/admin/verify.cjs`（从仓库根目录执行，需要仓库 frontend 的 Playwright 和 Microsoft Edge）。验证七页渲染、账号禁用恢复、下架原因校验、镜像新增停用、日志同步、空搜索、分页和窄屏溢出。截图存于 inspection 目录。

后续真实联调需落实：禁用账号的会话失效机制、下架课程的师生访问行为、镜像实际可达性、服务监控接口。原型不模拟这些后端行为。
