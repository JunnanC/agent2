# 教师端 HTML 原型

打开 index.html，从侧栏进入教学概览、我的课程和通知。各页面使用公共 styles.css 和 app.js，无需构建。

共 14 个业务页面（另保留旧验证入口跳转页）：教学概览、我的课程、课程概况、学生管理、学生个人数据、实验设计、实验编辑、实验发布、发布详情、报告评审、教学分析、验证工作台、验证报告、通知。

评审演示支持全部筛选结果跨分页全选（每页 5 条，共 12 条）、AI 建议评分、批量采纳、手动修改及教师最终确认。AI 评分为本地示例计算，不调用真实模型。验证报告支持必填检查、浏览器草稿保存和模拟提交；代码运行展示固定示例输出，不执行代码。

所有数据为示例，不接入现有业务服务，不改动正式教师应用。新建课程、邀请导入、创建发布仅展示表单，未实现真实创建。批量评审状态仅在当前页面有效，报告草稿使用 localStorage。

视觉沿用 student-web/src/styles.css 与 admin-web/src/console/console.css：灰白底色、深绿主操作、248px 侧栏、中文系统字体、12px 面板圆角及 8px 控件圆角。无装饰性渐变或循环动画，统计图作为页面视觉重点。

设计方法：unslop by Damir Sokolovsky (@heydamir), CC BY 4.0，https://heydamir.design/unslop 。

验证入口：我的课程 → 课程 → 实验设计 → 具体实验的“验证实验”，或从实验编辑、发布详情进入验证工作台，再填写并提交验证报告。validate.html 旧入口自动跳转至课程实验列表。
