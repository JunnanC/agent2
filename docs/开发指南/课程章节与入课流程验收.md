# 课程章节与入课流程

核对日期：2026-11-17。对应 `bugfix1` 分支。

## 当前行为

- 教师创建课程无需填写课程代码，服务端生成包含时间信息和随机尾码的唯一标识。历史课程代码保留。课程代码与邀请码分开。
- 课程采用固定入课规则：教师输入学生账号或邮箱直接添加，学生使用邀请码申请则先进入待审核。教师名单导入也使用教师授权的直接加入路径；容量与有效成员分配仍经过原有服务。
- 教师“我的课程”显示可用邀请码及有效期，可复制完整新码。新码加密保存；历史摘要不可反解，仍可校验，教师可生成新码。完整邀请码只在授权教师接口返回。
- 课程章节和学习材料为上下两个独立模块。章节编辑提供名称和章节说明，序号自动生成：已有第三章，新建时显示只读“第四章”，名称只需填写“云教学实验”。新序号取已有最大位置加一；编辑既有章节保留原位置，兼容历史标题中的“第几章”前缀。
- 新章节保存为草稿，教师独立发布。已发布章节先撤回再修改，撤回后可重新发布。AI 内容先评审再采纳到说明。
- 学习材料模块独立选择所属章节，不切换上方章节编辑器，添加表单仅名称和附件。附件最多 10 MB，扫描通过后保存为材料草稿；发布章节不会自动发布材料。支持 PDF、DOCX、PPTX、XLSX、文本、Markdown、CSV 和常见图片。列表返回真实文件名和大小，材料可单独发布、撤回及重新发布。
- 实验发布时选择课程章节；实验列表也可将历史实验归章或重新归章。归章只修改导航关联，不更改已发布题目快照与成绩事实。补做实验继承来源实验的课程章节。
- 学生章节详情展示本章说明、已发布材料和本人被分配的实验；草稿章节及其材料不公开。历史未归章实验保留课程概览入口，教师可逐项归章。
- 实验模板内部章节与课程章节分别管理。可从课程章节复制标题和说明到模板内部章节，再组织题目；空章节列表及不可编辑版本有明确提示。
- AI 根据章节名称生成独立、可编辑的草稿，教师评审后主动采纳，再保存、发布章节。生成失败保留教师编辑区，生成结果不会自动公开。
- 选择题批量导入支持既有 XLSX 模板以及规范 DOCX。Word 每题以 `1. 题干` 开始，选项分段使用 `A.`、`B.`，后接 `答案：B`、`分值：5`、`解析：说明`；多选答案如 `A,C`。先解析预览，再确认追加，错误标明段落位置。不支持旧版 DOC 或扫描图片识题。
- 导航、登录页和浏览器标签统一采用云与实验烧杯图标，三端公共目录提供 SVG 和 256 像素 PNG。

## 主要新增接口

| 方法 | 路径（省略 `/api/v2`） | 用途 |
| --- | --- | --- |
| GET | `/teaching/course-invitations` | 当前教师拥有的课程可用邀请码汇总 |
| POST | `/teaching/courses/{course_id}/direct-invitations` | 指定学生直接加入，重复添加不重复建成员 |
| PATCH | `/teaching/courses/{course_id}/chapters/{chapter_id}` | 按版本更新章节草稿/已撤回章节 |
| POST | `/teaching/courses/{course_id}/chapters/{chapter_id}/materials/upload` | 章节材料上传、扫描及草稿保存 |
| POST | `/teaching/courses/{course_id}/chapter-drafts/generate` | 生成并保存教师可评审的 AI 草稿 |
| POST | `/teaching/courses/{course_id}/template-versions/{version_id}/import-course-chapter` | 复制课程章节内容到模板内部章节 |
| PATCH | `/teaching/courses/{course_id}/experiments/{publication_id}/course-chapter` | 实验归章，不改已发布题目快照 |

写操作沿用幂等键；章节、模板及实验更新带 `If-Match`。完整字段以生成的 OpenAPI 为准。实验和学生任务响应增加 `course_chapter_id`。

## 部署要求

1. 使用迁移账号执行 `python manage.py migrate`，应用新增迁移。迁移增加章节正文、加密邀请码、AI 草稿表、实验课程章节关联；回填章节旧摘要，固定既有课程入课配置。历史实验的章节关联允许为空，避免猜测归属。
2. 重新执行现有 MySQL 授权初始化流程，使运行账号获得 `courses_chapter_draft` 的 SELECT、INSERT 权限。
3. 更新并应用 MinIO 的 `infrastructure/minio/app-policy.json`，允许应用账号访问 `course-materials/*`。附件仍使用 ClamAV 扫描及受控下载。
4. 章节 AI 默认复用 `AI_*` 的模型服务配置；也可单独设置 `CHAPTER_AI_API_KEY`、`CHAPTER_AI_BASE_URL`、`CHAPTER_AI_MODEL_NAME`。未配置服务时返回明确错误，不返回本地规则回复充当生成内容。
5. 重建后端和三端前端资源，按原部署流程更新服务。保持邀请码 HMAC 密钥稳定，避免既有摘要校验及加密码读取失效。
