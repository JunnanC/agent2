# 轻量编程执行镜像

当前只构建 [Dockerfile.stdio](../../runtime/algorithm-workspace/Dockerfile.stdio)，不再构建 code-server、ttyd、调试扩展和工作区代理。

Python 3.14.0、GCC/G++ 12.2.0、Java 17.0.21.1、Go 1.25.1 在构建时检查。草稿存储在平台，运行和正式判题按需创建非 root、禁网、只读根文件系统的临时容器。标准答案始终保留在可信 worker，逐用例输入，输出比较由 worker 完成。

构建、五语言验证、正式种子和浏览器验收见 [轻量答题验收](轻量答题验收.md)。Docker Local 支持真实执行；Swarm 判题尚未实现，发布预检明确拒绝。
