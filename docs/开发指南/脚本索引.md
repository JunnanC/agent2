# 脚本索引

当前入口以 `scripts/` 实际文件为准。核对日期：2026-11-12。

| 入口 | 用途 |
| --- | --- |
| `scripts/dev/start.sh`、`stop.sh` | 项目 Compose 启停，保留数据卷 |
| `scripts/frontend-dev-up.ps1`、`frontend-dev-down.ps1` | 三端 Vite 与代理开发入口 |
| `scripts/dev/export-openapi.ps1` | 导出 OpenAPI JSON 并更新客户端生成类型 |
| `scripts/verify/backend-local.ps1` | 后端、迁移、代码检查和配置验证 |
| `scripts/verify/assessment-runtime-smoke.py` | 真实五语言、多文件、资源限制与隔离验证 |
| `frontend/e2e/assessment.spec.ts` | 三种实验的浏览器保存、运行、交卷旅程 |
| `seed_assessment_e2e` | 固定三类新链路测试样本，见[验收说明](轻量答题验收.md) |
| `scripts/cd/deploy.sh` | ACR 镜像发布、资源预检、备份和迁移 |
| `scripts/deploy/deploy-swarm.ps1` | Swarm 模板部署；不代表支持分布式编程判题 |

旧开通、工作区、报告与旧评审的专项种子、累计集成脚本已删除，不保留指向旧协议的兼容入口。其他账号、课程及治理脚本仅验证自身前置条件，不能替代新答题链路验收。

日常前端在 `frontend` 执行 `npm run typecheck`、`npm test`、`npm run lint`、`npm run build`。需要真实容器与队列时使用独立项目、数据卷和运行资源；不要在日常学生任务上执行验收或清理。
