## 范围与边界

- 运维聚合复用 Outbox、补偿、实例、配额和审计事实；分析投影、通知、开放 API 和运行日志查询补齐 Prometheus 指标与结构化结果。
- MongoDB runtime_logs 查询设置 created_at、trace_id 索引和 TTL；Replica Set/连接健康返回降级状态，MongoDB 不可用时日志查询返回空结果而不阻塞业务接口。
- admin-web 增加投影新鲜度、质量/成本、通知、集成投递和运维摘要；只验证本地 Compose 的可观测和恢复边界。

- 全量后端 pytest、Ruff、OpenAPI、三端 ESLint/Vitest/TypeScript/build 和 Compose 配置由 `scripts/verify-p13-c.ps1` 执行。
