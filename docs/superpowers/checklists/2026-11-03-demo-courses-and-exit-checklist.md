# 演示课程数据与学生退出课程 Checklist

## 实现完整性

- [ ] 默认演示规模包含扩充后的多门独立课程（验证：运行种子 dry-run 并检查课程数）。
- [ ] 重复种子使用稳定课程代码复用已有课程（验证：检查数据库中课程代码无重复）。
- [ ] 已加入课程卡片显示“退出课程”（验证：学生端打开我的课程页面观察操作区）。
- [ ] 待审核申请显示“撤回申请”（验证：学生端打开我的申请页观察操作区）。

## 集成

- [ ] 允许退出时确认调用退课接口并刷新列表（验证：组件测试断言调用参数和缓存失效）。
- [ ] 退出受阻时展示后端阻塞原因且确认按钮禁用（验证：组件测试）。
- [ ] 撤回申请调用撤回接口而不调用退课检查（验证：组件测试）。

## 编译与测试

- [ ] `npm run typecheck` 通过。
- [ ] 学生端相关 Vitest 通过。
- [ ] `npm run build:student` 通过。
- [ ] Python `compileall` 通过。

## 端到端场景

- [ ] 学生进入“我的课程”→点击“退出课程”→填写原因→确认→看到成功提示并从激活课程列表消失。
- [ ] 学生进入“我的申请”→点击“撤回申请”→确认→看到撤回提示并刷新申请状态。
