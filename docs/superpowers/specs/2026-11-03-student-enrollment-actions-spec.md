# 学生选课状态操作 Spec

## 目标与需求
- 待审核申请在我的课程的申请区域和我的申请中均可撤回；撤回后可重新申请。
- 只有 ACTIVE 选课允许进入课程详情和课程内容；待审核、已撤回、已退出均无学习权限。
- 已加入课程在课程列表、我的申请和课程详情中提供退出入口，保留现有退出前检查和原因确认。
- 撤回或退出成功后刷新选课、课程、学生汇总、上下文与实验缓存；详情中退出后返回课程列表。
- 保留有效邀请码直接加入、无邀请码等待教师审核的规则。

## 验收
- 待审核申请展示撤回按钮，不展示进入课程链接。
- 服务端禁止待审核、撤回、退出用户读取课程详情和材料等内容。
- 申请撤回、重新申请、教师同意、学生退出的完整流程可通过接口测试。
- 页面测试验证按钮、导航和列表刷新；类型检查、学生构建通过。
