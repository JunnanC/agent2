# 首页待完成任务分页 Spec

## 背景与目标
当天待办任务较多时，首页右侧放大列表过长；通过分页限制一次展示的任务数量。

## 功能需求
- F1：当天任务每页展示 4 项，保留原有顺序、课程、状态和点击入口。
- F2：超过 4 项时提供上一页、下一页和当前页/总页数，保留当天任务总数；首尾按钮禁用。
- F3：切换日期回到第一页；任务数量减少时自动使用有效页码；空日期显示原有空状态。

## 约束与范围
复用现有按钮样式，分页支持键盘操作和窄屏换行。本次仅分页首页已加载的当天任务列表，不调整接口、日历统计或任务筛选规则。

## 验收标准
- AC1（F1、F2）：9 项任务分三页展示为 4、4、1 项，各项可点击，显示总数 9，首尾按钮状态正确。
- AC2（F2）：0 至 4 项任务不显示分页控件。
- AC3（F3）：第二页切换到其他日期后显示第一页；任务刷新减少后仍能看到有效任务，空日期保持空状态。
