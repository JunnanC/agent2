# 学生退课通知老师 Spec

- F1：学生确认退课后立即变为已退出，无需教师同意；提交事务中可靠记录通知事件，由现有通知消费者投递。
- F2：课程负责人及有效且有选课管理权限的助教收到教师门户站内通知；其他课程老师、撤销成员或过期权限不接收。
- F3：通知显示学生、课程、退出原因、时间以及“已生效，无需审批”，可打开课程选课管理，不提供同意/拒绝操作。
- F4：教师门户提供通知入口、未读计数、正文、已读操作及定期刷新；重复消费和退课请求重放不重复通知，失败或回滚的退课不发通知。

验收：带未完成任务退课先成功，再消费事件收到教师通知；无关老师收不到，重复消费不重复，撤回申请/教师移除不冒充学生退课通知；教师界面可查看正文并标记已读。
