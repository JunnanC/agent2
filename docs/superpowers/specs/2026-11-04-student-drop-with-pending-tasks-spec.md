# 学生有待办时退课 Spec

## 目标与需求
- F1：有效选课的学生即使有未完成实验任务，也能填写原因并确认退出；退出检查与提交执行同一规则。
- F2：退出后课程和未完成任务从当前学习列表移除，停止提供任务操作入口；学习历史、任务和成绩记录保留。
- F3：保留所属学生、选课状态、版本、原因和幂等校验；其他阻塞规则及教师移除规则保持现状。
- F4：退课弹窗明确说明有未完成任务也可退出，退出后失去学习权限、记录保留。

## 范围
调整学生退课规则及学生当前任务列表。复用已有课程和工作台对非有效选课的权限校验。不删除任务，不改变实验归档、运行资源回收或重新选课分配流程。

## 验收
真实待办存在时检查允许、提交成功，原课程不可访问、当前任务列表不再显示该待办，历史仍保留；非有效选课与其他阻塞仍拒绝；相关后端和前端测试通过。
