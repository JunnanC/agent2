# 用户端新版接口页面接入 Spec

## 背景与目标
基于当前 OpenAPI 与 backend/apps 路由，复核已有接口改动，并将尚无调用入口的学生功能接入现有界面。

## 功能与验收
- F1：我的课程可查看按学年、学期组织的学习历史与实验成绩；空数据、失败可观察并重试。
- F2：待审核申请可撤回；在读课程退出前读取最新选课记录及退出检查，显示阻塞原因，携带版本提交并刷新课程、课表和历史。
- F3：课程及任务可使用教师开放的 Agent 模式建立会话、发送消息、等待异步回复、查看引用、反馈及人工确认工具调用。失败可见且不能重复并发提交。
- F4：课表上传、列映射、确认及异步完成在页面可用，并可查看具体行错误和导入汇总。
- F5：已发布评审结果支持退回后的查看及重新提交入口；教师 AI 草稿不暴露给学生。

## 边界
保留工作区已有修改；不新增后端能力，不执行真实退课、密码修改或工具调用。不改教师 AI 评审管理页面；用户资料安全和 OIDC 已有客户端能力保留。

## 验收标准
通过请求契约测试、页面行为测试、三端类型检查和学生构建；模拟测试与真实联调分别报告。
