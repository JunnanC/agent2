# 通知正文与截止提醒 Spec

## 背景与目标
通知已有详情弹窗，但查看后仍未读，实验分配消息缺少实验名称。

## 功能需求
- F1：查看通知立即打开正文并自动标记已读，保持在通知页面；失败可重试。
- F2：新实验通知写明教师发布的实验名称、所属课程和截止时间，提供实验入口；补全已有空泛实验、选课、账号创建、教师资格更新和资源配额通知。
- F3：截止前24小时内，每个实际截止时间只提醒一次尚未完成或需要修改的实验；已提交待评审、已完成、已退出课程或已关闭实验不提醒。延期以新截止时间为准。

## 非功能需求
沿用版本控制与通知偏好；重复扫描和并发不产生重复提醒。

## 边界
仅应用内通知；不增加邮件和短信。

## 验收标准
- AC1：打开未读详情后未读数量减少，正文保持显示，已读通知不重复请求。
- AC2：真实实验分配生成包含实验、课程和截止时间的正文，历史补全保留已读状态。
- AC3：临近截止只有符合条件的学生收到提醒，重复扫描无新增，延期后按新截止时间提醒。
