# 用户端接口接入 Spec

## 目标与范围
按 frontend/openapi.json 和后端实际序列化补齐用户门户接口：课表及导入、资源汇总、学习历史、选课退出、课程问答、Agent、通知偏好、个人安全和附件下载。

## 功能需求
- F1：提供与新契约一致的用户端调用和数据类型，保留已有页面行为。
- F2：课程页显示资源汇总并支持课程提问、回复；个人页读取和保存通知偏好。
- F3：我的课程提供课表查看和文件导入，完成字段映射后确认，等待异步导入结果。
- F4：通知读取和已读操作遵循真实返回字段、版本锁及幂等要求。

## 约束
沿用 Cookie、CSRF、错误处理和 React Query；保留工作区已有修改。此轮不重新设计所有页面，不发布远端代码。尚无页面入口的能力先作为类型化客户端提供。

## 验收
新请求路径、请求体和并发头有契约测试；文件保持 multipart；已有学生页面及共享客户端通过类型检查、相关测试和构建。真实服务联调与本地模拟测试分别记录。
