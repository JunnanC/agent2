# 通知正文与截止提醒 Plan

## 组件与接口
- Notifications 页面：查看事件选中通知并调用现有 markNotificationRead，成功刷新列表和未读数；失败仍显示详情并提供重试。
- 实验分配事件：携带课程、实验名称及截止时间快照。
- 通知服务：解析实验分配事件生成可读正文；历史记录通过管理命令补全，仅更新展示字段并保留 read_at。
- remind_unfinished_experiments：按有效截止时间查询活跃课程的未完成任务，以任务标识和截止时间哈希作为去重键，通过已有通知唯一约束创建消息。
- Celery Beat：每60秒扫描，阈值 NOTIFICATION_DEADLINE_REMINDER_HOURS 默认24小时，遵守通知静音和应用内渠道偏好。

## 数据与交互
实验发布 → 学生任务分配事件 → 通知消费 → 学生查看正文并自动已读。
定时扫描 → 状态和截止时间过滤 → 原子创建唯一通知 → 学生通知列表。

## 技术决策
复用通知模型，无新增表；已提交待评审不催交，驳回修改仍提醒；空有效截止时间回退到发布截止时间。
