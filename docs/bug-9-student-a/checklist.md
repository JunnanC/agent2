- [ ] AC1 材料预览/下载独立且受控（验证：组件测试）。
- [ ] AC2 附件报告无正文输入，教师附件可下载，扫描仍阻止未安全附件提交（验证：页面与后端测试）。
- [ ] AC3 题目列表切换先保存、样例与自测输出分区（验证：assessment 测试）。
- [ ] AC4 两列独立滚动，活动章节同步，窄屏自然滚动（验证：课程测试和浏览器）。
- [ ] AC5 学号与旧标识登录、重复/非法批次逐行错误、权限和课程名单导入（验证：后端服务与 API 测试）。
- [ ] 集成：共享客户端类型与 OpenAPI 一致（验证：生成 API 和 typecheck）。
- [ ] 前端 typecheck、相关测试、build 通过（验证：npm scripts）。
- [ ] 后端迁移未遗漏、相关测试与 lint 通过（验证：Django/pytest/ruff）。
- [ ] 端到端：管理员创建学生 → 学号登录 → 教师学号导入课程（验证：集成测试）。
- [ ] 端到端：学生进课程 → 预览/下载 → 编程自测 → 附件交卷（验证：浏览器或集成测试；注明 mock/真实环境）。
