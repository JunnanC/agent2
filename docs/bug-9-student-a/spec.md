# 学生端 A Spec

## 背景
两人协作方案 A 覆盖学生学习材料、附件报告、编程自测、章节滚动和学号接入。基于 agent2 main 0f11379；用户授权自主完成，不逐段等待审批。

## 目标
完成 A 的五项交付，保留既有安全链路，并给 B 提供教师导入契约。

## 功能需求
- F1 文件材料提供独立预览和下载操作，均使用受控授权；危险地址拒绝打开。
- F2 报告以附件提交，去掉正文输入；显示教师附件下载，保留扫描、授权、版本控制与历史。
- F3 编程题列表直接切换，切换前保存；显示实际提供的样例（最多两组，不伪造缺失样例）；自测输入、标准输出和错误输出明确分区。
- F4 桌面章节导航和内容独立滚动且活动章节同步，窄屏恢复自然文档滚动。
- F5 学生支持学号登录；平台管理员可批量创建学生，教师可按学号导入课程；逐行返回错误与成功结果，保留旧邮箱/用户名登录。

## 非功能需求
- N1 不提交本机配置、用户已有未跟踪文件；不修改 B 的教师界面。
- N2 写操作复用认证、CSRF、幂等、审计；学号全站唯一，空学号兼容旧账号；禁止登录标识歧义。
- N3 邮箱继续必填且唯一；初始密码由管理员按现有密码规则逐行提供，不建立默认共享密码，不变更已有首次登录策略。
- N4 前端类型检查、相关测试、构建，后端权限/迁移/业务测试须记录实际结果。

## 不做的事
B 的通知、发布配置、教师名单导入 UI、教师分析与模板布局；第三方学校认证；更改邮箱可空或强制首次改密策略。

## 验收标准
- AC1 对同一材料分别点预览和下载，得到不同展示行为，错误可重试。（F1）
- AC2 学生看到附件上传，无正文输入；未扫描附件不能交卷，教师附件可授权下载。（F2）
- AC3 点题目列表切换不丢草稿；看到两组已提供样例；运行自定义输入并分别显示输出与错误。（F3）
- AC4 长章节桌面左右独立滚动并同步选择；窄屏无横向溢出。（F4）
- AC5 学号/旧邮箱/用户名登录兼容；重复学号、非法密码、越权导入拒绝，混合批次返回逐行结果，课程导入可按学号匹配。（F5）
