`VersionedModel` 使用 `row_version` 和比较交换更新，禁止任意保存覆盖或硬删除；`AppendOnlyModel` 的既有记录不可修改、删除。唯一约束、外键和状态枚举以模型与迁移为准。

## HTTP 与门户

API 前缀为 `/api/v2/`，健康与就绪入口分别为 `health`、`health/ready`，Schema 为 `schema`。受控下载位于 `/files/<token>`，工作区代理位于 `/workspace/`，不属于普通业务 API 前缀。

| 入口上下文 | 用途 |
| --- | --- |
| `USER` | 学生门户；不因前端目录名不同而改变 |
| `TEACHING` | 教师门户及课程能力授权 |
| `PLATFORM` | 管理门户 |
| `INTEGRATION` | 集成 OAuth 和开放接口；使用独立的机器认证上下文 |

浏览器使用 Django Session Cookie，写操作携带 CSRF。代理按 Host 写入门户上下文，后端验证代理来源及 `X-Proxy-Context`；不能在前端伪造 `X-Portal` 绕过入口。

## 返回值、分页与并发

- 常见成功响应使用 `data` 和 `meta.trace_id`；列表结构和分页方式以具体 serializer、接口响应为准，不假设所有列表一致。
- 统一错误体为 `{ error: { code, message, detail, trace_id, retryable } }`，实现见[异常处理](../../backend/education_experiment_platform/api.py)。
- 通用页码分页默认每页 20 条，上限 100；部分接口使用游标，见[分页实现](../../backend/apps/core/pagination.py)。
- 需要版本前置条件的写操作携带 `If-Match: "<row_version>"`。缺失或格式错误不能直接写入；版本冲突返回 412，客户端重新读取并处理冲突。
- [幂等中间件](../../backend/education_experiment_platform/middleware.py)要求大部分 API POST，以及报告草稿和审核分项的指定 PUT 携带 `Idempotency-Key`。登录、注销等显式豁免；具体服务负责对应幂等语义。同一业务命令重试复用同一个键，键最长 128 字符。
- 401 处理会话失效，403 处理资格与权限，409 处理业务状态冲突，412 处理版本冲突，428 处理缺少前置条件；最终以错误码和接口实现为准。

## 工作区与文件

- `GET /api/v2/tasks/<task_id>/workbench` 聚合学生可见任务、环境与提交状态；进入、会话、快照、存储作业和运行记录见[工作区路由](../../backend/apps/workspaces/urls.py)。
- 模板、公开数据和测试对象必须满足归属、用途、扫描与生命周期要求；不能只检查对象 ID 存在。
- 文件写入和下载使用受控对象、扫描结果及授权；签名地址、上传凭据和工作区令牌不写入长期日志或浏览器持久存储。
- 工程快照绑定内容摘要；正式测试与成果提交校验任务、快照和执行证据的一致性。旧通过结果不能覆盖语言切换或工程变更后的测试要求。
- SSE 位于 `/api/v2/events/stream`，按账号、门户和课程授权筛选事件；客户端重连或收到 resync 提示后重新查询 REST。事件只提示变更，不作为最终业务状态。当前 Nginx 仅放行学生端事件流，教师端和管理端入口返回 403；后端事件过滤能力不能当作三端入口均已开放。

## 修改接口时

1. 同步修改模型或服务、serializer、路由与权限测试；结构变化提交新迁移，不改写已执行迁移。
2. 使用[契约导出脚本](../../scripts/dev/export-openapi.ps1)更新 OpenAPI 和生成类型。
3. 同步 [API 客户端](../../frontend/packages/api-client/src/index.ts)和相应页面；执行后端针对性回归、前端类型检查与相关测试。
4. 核对学生可见字段、跨门户访问、并发冲突及重试行为；验收结果写入 `outputs/`。
