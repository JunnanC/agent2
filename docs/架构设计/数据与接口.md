# 数据与接口

核对日期：2026-11-12。全量字段以 `backend/apps` 模型、应用路由与生成的 OpenAPI 为准。

## 事实关系

| 链路 | 当前模型 |
| --- | --- |
| 模板与发布 | Template → TemplateVersion → TaskPublication → ExperimentTask |
| 公开与私有题目 | TemplateTask、PublicationTask；question_spec 与 marking_spec 分开，学生响应只读白名单 |
| 草稿 | AnswerDraft；按题目、语言独立的 CodeDraft；ReportDraft |
| 不可变提交 | AssessmentSection 有效提交指针 → SectionSubmission → QuestionSubmission；报告版本由编程卷引用 |
| 代码快照 | WorkspaceSnapshot → ObjectAsset；不关联容器或会话 |
| 评分 | QuestionGrade 隐藏测试分组评分；ReportGrade 教师评分；总成绩按有效分卷投影 |
| 量表 | Rubric → RubricVersion → RubricCriterion |
| 归档 | ArchiveJob → ArchiveManifest、ArchiveVerification、导出授权 |
| 执行配额 | QuotaReservation、RuntimeCapacityReservation；容器使用受管标签与期限回收 |

选择题、编程与报告分别统一交卷。草稿更新使用 If-Match；交卷使用 Idempotency-Key，在事务中验证全题集和草稿版本。旧提交的异步结果不能替换新有效提交。成绩公开、评分完成与是否交齐分别计算。选择题答案在服务端控制的截止时间后公开；编程结果不返回隐藏逐用例日志。

主要入口：`/api/v2/tasks/{task_id}/assessment`、题目草稿和运行、`sections/choice/submissions`、`sections/programming/submissions`、编程报告草稿、教师 assessment 评审和 report-suggestion。精确方法与字段见 [OpenAPI](../../frontend/openapi.json) 和 [客户端](../../frontend/packages/api-client/src/assessment.ts)。

报告附件继续走扫描及受控下载。学生只能下载本人代码、报告和公开材料；教师需课程权限及提交事实。隐藏测试与参考解不通过学生文件入口、归档、通知或 Agent 暴露。归档保留固定提交，校验成功才结束任务；失败可重试。

旧工作区、会话、开通、代理、单独提交报告、旧评审及自动检查接口已移除。删除模型通过新增迁移执行，历史迁移不改写；没有旧业务记录转换器。

生成契约：从根目录执行 `./scripts/dev/export-openapi.ps1`。同时维护前端共享客户端、类型、查询键与测试。现有 Cookie、CSRF、门户隔离、课程权限、错误包络及审计规则继续适用。
