# 系统架构

核对日期：2026-11-12。以当前源码为准。

浏览器通过 Nginx、Kong 访问 Django API。学生编辑器属于 React 学生端，使用 CodeMirror；草稿存储在 MySQL，代码快照、附件与私有测试存储在 MinIO。浏览器不访问 Docker，不再建立 IDE 会话或代理连接。

```text
教师题目编辑 / Excel 导入 → 模板预检 → 不可变发布快照
                                         ↓
                                  每名学生一份任务
                          ┌──────────────┴──────────────┐
                     选择题草稿                    分语言代码草稿与总报告
                          ↓                            ↓
                     选择题卷提交                 编程与报告卷提交
                          ↓                            ↓
                       自动评分                 隐藏判题 + 教师报告评分
                          └──────────────┬──────────────┘
                                 有效分卷成绩投影
```

运行与正式判题使用 `apps/provisioning/stdio.py`，worker 按需创建临时容器，执行后回收。隐藏测试调度、标准答案及输出比较位于可信 worker；学生进程只收到当前输入。运行不读取隐藏测试。五种语言共用精简 stdio 镜像，无 code-server、ttyd 或调试扩展。

MySQL 保存业务事实，Redis 支持缓存、Celery 和事件转发，MinIO 保存版本化对象，MongoDB 保存脱敏运行日志。Outbox、幂等记录、行版本、审计和补偿沿用平台机制。Beat 持续调度待执行与重试的判题作业。

## 业务目录

| 模块 | 职责 |
| --- | --- |
| accounts、courses | 身份、选课、课程权限、教学内容和课表 |
| labtemplates | 题目编辑、Excel 导入、私有测试、参考解、镜像与发布预检 |
| experiments | 学生任务、草稿、两份交卷、运行、成绩公开、退回重交 |
| provisioning | Docker 镜像管理、短生命周期执行器、隐藏判题及容量预留 |
| workspaces | 复用的不可变代码快照；保留 app 与表名以维护迁移历史 |
| reports | 总报告草稿、版本、附件扫描与下载授权 |
| reviews | 教师报告量表；正式报告评分与 AI 建议入口位于 experiments |
| archives | 学生安全归档、校验、重试、导出、保留期 |
| governance | 镜像审批、运行资源、配额、健康与预算 |
| agents | 课程问答、报告辅导与受控只读工具，不读取私有答案和隐藏测试 |
| analytics、notifications、integrations | 总成绩统计、通知与受控外部接口 |

学生任务不再依赖常驻容器。旧开通、会话、编辑代理、单独报告交卷与人工代码评分已删除；不提供双链路开关或历史业务数据转换。历史数据库迁移保留，删除旧结构通过新增迁移实现。

首版编程真实执行支持 Docker Local。Swarm 分布式判题未实现，发布预检明确拒绝；不得把纯选择题或静态栈配置检查当成 Swarm 编程验收。
