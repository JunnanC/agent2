## 当前实现与边界

- 学生端采用 CodeMirror 轻量编辑、选择题与编程报告分卷交卷；五语言 stdio 临时容器执行，草稿不依赖容器。
- 题目发布快照、隐藏分组判题、报告人工评分、受控成绩公开与归档由新链路完成。旧 IDE、会话、常驻容器、旧评分与旧种子已清退。
- 编程以 Docker Local 验收；Swarm 分布式判题不支持，预检明确拒绝。
- 账号、课程权限、文件授权、Outbox、补偿、通知和统计沿用平台能力。准确接口见生成 OpenAPI。
- 测试种子及浏览器、容器验收见[轻量答题验收](开发指南/轻量答题验收.md)。生产环境容量、HA 与恢复仍需独立验证。

## 命名约定

- 文件、脚本、命令、测试、业务显示名称及文档标题直接按业务或功能命名，不再使用 `p01`、`p02`、`t10` 等阶段编号，不维护旧编号映射表。
- 脚本按 `scripts/dev/`、`scripts/verify/`、`scripts/deploy/` 分类，文件名使用小写单词和连字符；Python 模块和 Django 命令使用下划线。
- 过程目录使用 `YYYY-MM-DD-专项名称/`；项目文档按内容命名。已有数据库迁移、稳定查找键及协议版本需按兼容性要求迁移，不能机械替换。
- 历史命令和证据保留原始事实；执行命令时查当前脚本和配置。

## 维护规则

1. 本目录只维护当前说明。功能变更优先更新对应章节；不再按每个阶段、子任务或接口重复拆文档。
2. 每次更新核对对应源码、路由、配置或脚本，并更新该文档的核对日期。不能只改日期而保留过时内容。
3. API 字段以当前 serializer 和生成的 OpenAPI 为准；依赖版本以项目声明和锁文件为准，不手写另一套完整清单。
4. 被替代的旧方案、任务拆分和重复清单直接删除；需要追踪的实施结果保存在 `outputs/`，不复制整套旧文档。
5. 验收记录必须标明日期、环境、实际执行项和未验证项；文档整理不作为功能测试通过的证据。
