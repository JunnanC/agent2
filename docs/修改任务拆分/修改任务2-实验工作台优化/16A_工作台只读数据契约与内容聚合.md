# 实验工作台-A 工作台只读数据契约与内容聚合

## 一、目标

为用户端工作台提供一个经过权限裁剪的只读聚合接口，使前端不需要调用教师端模板接口，也不需要暴露完整运行配置。

## 二、接口

```text
GET /api/v2/tasks/{task_id}/workbench
```

权限：仅 `USER` Portal，且任务必须属于当前用户、选课仍有效、任务内容处于用户可见范围。

建议响应分组：

- `task`：任务标题、说明、状态、截止时间、报告策略、允许操作和阻断原因。
- `content`：目标、步骤、限制、交付物等公开实验内容。
- `template`：模板名称、版本号、依赖、工作区能力、手册资产和起始文件资产 ID。
- `tests`：公开测试数量、显示摘要、最近执行摘要。
- `provisioning`：装载状态、当前阶段、阶段事件和进度。
- `submission`：报告/非报告提交策略和当前是否可提交。

## 三、建议实现位置

新增或调整：

- `backend/apps/workspaces/selectors.py`
- `backend/apps/workspaces/serializers.py`
- `backend/apps/workspaces/views.py`
- `backend/apps/workspaces/urls.py`
- 可新增 `backend/apps/workspaces/workbench.py` 组织聚合逻辑。

跨 app 读取使用公开 selector 或 serializer，不直接在 View 拼接跨领域数据库字段。

## 四、数据安全要求

不得返回：

- hidden test 输入和期望输出。
- 判题容器路径、Docker service ID、runtime 内部端点。
- 工作区 token、签名下载 URL、Cookie 值。
- 其他学生、其他课程或教师端专属内容。

模板文件通过 `ObjectAsset` 的授权下载流程访问：

```text
POST /api/v2/files/{asset_id}/download-grants
GET /files/{token}
```

## 五、前端契约同步

接口稳定后同步：

- 后端 OpenAPI。
- `frontend/openapi.json`。
- `frontend/packages/api-client/src/generated/schema.d.ts`。
- `frontend/packages/api-client/src/index.ts`。
- `frontend/packages/query-keys/src/index.ts` 增加 `workbench(taskId)`。

## 六、测试

- 当前用户可以读取自己的任务工作台。
- 其他用户访问返回资源不存在或权限错误，不返回任务存在性细节。
- 教师端和管理端不能使用 USER 工作台接口获得学生 token。
- hidden test 字段不会出现在 JSON、OpenAPI 示例或日志中。
- 模板资产未授权、已扫描失败或已撤销时返回可识别的业务错误。
- 接口不改变任务、Session、装载作业或 Outbox。

## 七、完成标准

- API、Serializer、selector、权限和 OpenAPI 完成。
- 不新增非必要 migration。
- 后端定向测试覆盖权限、范围和敏感字段裁剪。
- 前端类型已生成并能被用户端编译。
