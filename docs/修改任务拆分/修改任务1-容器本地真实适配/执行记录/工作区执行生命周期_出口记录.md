## 结果与问题

```text
正常路径结果：FakeRuntime RUN_CHECK 仍返回“RUN_CHECK accepted by FakeRuntime”，同时创建 PASSED execution run；DOCKER_LOCAL 进入 QUEUED 并可由 Celery worker 执行。
越权路径结果：旧 token/过期 session/非本人 task 不能创建或查询 execution run；execution id 详情要求 task scope 匹配。
状态冲突结果：重复请求复用执行事实；已终态 run 不会被 worker 再次推进；无 snapshot 的真实驱动请求明确 REJECTED。
```
