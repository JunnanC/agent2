## 结果与问题

```text
正常路径结果：提交报告复制最新终态 WorkspaceExecutionRun 的状态、摘要、规则 digest、快照 digest 和输出资产 ID；教师预览可见同一执行快照。
越权路径结果：学生不能提交其他 task 的 run/asset；教师下载需课程 REVIEW_SUBMISSION；未提交 execution asset 不可通过通用文件接口访问。
状态冲突结果：QUEUED/RUNNING 或无 run 的新 DOCKER_LOCAL 任务不能提交；旧快照执行不能替代当前快照执行；报告提交后学生无写接口且 ReportVersion append-only。
资源限制结果：T06 只冻结并展示 P08 已保存的 status/error/result_summary/rule summary；CPU、内存、超时和网络强制留待 T10 真实 judge。
回收和对账结果：执行对象和报告字段使用 PROTECT；容器、卷、对象 retention 和孤儿回收留待 T08/T10。
日志、trace 和指标结果：报告 Audit/Outbox payload 包含 execution_run_id、status、rule digest、snapshot/asset ID 和 trace；不包含原始 stdout/stderr、Token 或源码。
敏感信息泄漏检查：响应只返回 opaque public_id/digest/status/摘要；对象 key 和下载 token 不写入报告事实。
已知限制：FakeRuntime 兼容路径在历史无执行证据报告重提时生成兼容 PASSED 事实；新 DOCKER_LOCAL 任务严格要求先运行；真实输出对象和 judge 资源限制未在本阶段验证。
未解决阻塞：无代码阻塞；真实 Docker/MinIO/Celery/Playwright E2E 和生产环境门禁待 T10/T11。
```
