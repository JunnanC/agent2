# Bug-10 B 端需求

教师按教学班配置、复制和测试 CPU、内存及语言对应的实验环境，并查看使用关系和实际运行采样。教师选择环境、编辑指导、出题和设置三项满分，可生成 AI 草稿，经人工核对后发布。学生在工作台阅读指导、保存代码、用公开样例自测并逐题正式提交，另交 Word 报告。正式结果保持隐藏用例隔离。

教师批量生成 Word 报告建议，核对正文批注、分数与评语，必要时人工补评。截止后一次性确认并公布整次实验成绩。待评报告或未完成的正式评测会阻止发布。发布后结果与报告锁定，重复确认返回同一结果。学生只读查看自己的分项得分、批注、评语及可公开的题目解析。

既有实验沿用历史快照和权限。对接使用现有教学班、实验、任务和学生 ID，按是否应做提供已发布成绩。
