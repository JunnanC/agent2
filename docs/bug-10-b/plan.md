# Bug-10 B 端设计

在实验领域保存班级环境配置、实验草稿和成绩发布日期。通过既有发布服务冻结题目、环境和受众，运行 worker 使用冻结容量。沿用任务数据库、生命周期和对象存储。公开与私有用例在评测响应中以可见性区分。

复用报告附件服务及 Celery。Word 批阅从报告资产提取带段落编号的文本和样式，保存建议状态以及教师确认内容。发布事务按实验、任务和报告的顺序加锁，生成只读成绩结果，阻挡后续可影响结果的写入。已发布接口返回三项成绩和满分、截止和公布时间、提交状态和应做口径。

前端通过实验客户端接入既有教师发布页、报告评审组件和学生答题工作台。直接使用课程 ID 和现有路由。
