# 教学云实验平台项目介绍

后端开发兼项目经理 项目资料

## 项目基本信息

**项目名称**：教学云实验平台。**项目简介**：面向教学实验的在线平台，包含学生端、教师端、管理员端，支持实验发布、学生在线实践与教师评阅批改。

**团队分工**：共5人，后端开发兼项目经理1人；学生端、教师端、管理员端开发各1人；运维测试1人。

**角色调整**：评审后因需求和结构变化，由项目经理兼前端开发调整为项目经理兼后端开发。

## 技术栈与依赖

- **后端直接依赖**：Python 3.14；Django（模型/事务）、djangorestframework（API校验）、drf-spectacular（OpenAPI）、mysqlclient（MySQL驱动）、jsonschema（规则结构）；celery（异步）、redis（队列/事件）、docker（容器SDK）、boto3（MinIO文件）、httpx（网关HTTP）；argon2-cffi（密码哈希）、cryptography（构建参数加密）；uvicorn[standard]（ASGI启动）、gunicorn（仅声明）、pymongo（日志）、prometheus-client（指标）。
- **后端开发依赖**：pytest / pytest-django（测试）、Ruff（检查/格式化）、mypy（类型检查）、pip-tools（依赖清单）、types-PyYAML（类型声明）。
- **三端及共享包**：react/react-dom（渲染）、react-router-dom（路由）、@tanstack/react-query（缓存）、dompurify（HTML清理）；@edu/api-client（接口）、@edu/auth-client（认证）、@edu/event-client（SSE）、@edu/query-keys（缓存键）、@edu/ui（组件）、@edu/config（配置）。
- **前端开发测试**：TypeScript（类型）、Vite（构建）、openapi-typescript（接口类型）；Vitest/Testing Library/jsdom（单测）、@playwright/test（端到端）、ESLint（检查）。
- **基础设施**：MySQL（业务）、Redis（队列）、MongoDB（日志）、MinIO（文件）、ClamAV（扫描）；Nginx/Kong（入口）；Fluent Bit（日志采集）、OTel Collector（遥测）、Prometheus（指标）；Compose（单机编排）、Swarm（集群待验）。

## 个人职责与重点难点

**后端开发职责**：业务 API、数据模型、权限校验、状态流转、异步任务，以及三端接口联调与缺陷修复。

**项目管理职责**：需求拆分、任务分配、接口与验收标准约定、进度跟踪，以及前端和运维测试协作。

### 实验模板发布与任务一致性

**技术**：Django ORM、MySQL 事务、行锁及版本校验。**实现方式**：校验发布权限和资源依赖，固定模板快照并按选课对象生成任务；大批量分发通过 Celery 异步处理。**难点与验证**：防止模板、发布配置与任务不一致，回归重复发布和版本冲突。

### 环境准备与检查点及用例测试

**技术**：Celery、Redis、Docker SDK、boto3 和 MinIO。**实现方式**：异步准备容器；代码快照经扫描后存入对象存储，检查点关联快照；测试以幂等键去重，在事务提交后调度。**难点与验证**：会话归属、准备失败、超时与状态同步；检查点不等于整机备份。

### 教师评阅与跨端状态闭环

**技术**：DRF、Django 事务、MySQL、React Query。**实现方式**：校验评阅权限、状态、记录版本、自动测试进度及量规评分，保存决定并更新任务；前端刷新结果数据。**难点与验证**：保持学生结果、教师评分与任务状态一致，完成跨端回归。

## 架构与运维部署

![门户与后端异步运行架构示意](D:/all_of_project/edu-agent-platform/documents/项目评估材料/配图/后端运行架构.png)

- **后端**：backend/Dockerfile 基于 Python 3.14 slim 安装依赖、复制项目，以非 root 用户运行 Uvicorn，监听 8000；worker 和工作区网关复用镜像，使用不同启动命令。
- **三个前端**：infrastructure/nginx/Dockerfile 与 Dockerfile.prod 使用 Node 24 构建，将三端产物分别复制到 Nginx 1.29 的 /srv/student-web、/srv/teacher-web、/srv/admin-web，按 Host 区分门户，共用一份镜像。
- **本地集成**：docker compose --profile p14 -f docker-compose.dev.yml up --build 编排数据库、迁移、后端、worker 和网关等服务。默认端口 8080，Host 分别为 student.localhost、teacher.localhost、admin.localhost 与 api.localhost。
- **Docker Context 与集群**：build.context 是构建目录，Docker Context 是 CLI 的连接目标。发布前用 docker context ls 核对；p14-deploy.ps1 使用当前 CLI 连接。infrastructure/swarm/stack.yml 需版本化镜像、外部 configs/secrets 和 DNS/TLS；真实集群验收尚不能用本地通过替代。

**后续工作**：主链路缺陷回归、数据展示联调、Agent 需求与验收标准确认及后续开发。
