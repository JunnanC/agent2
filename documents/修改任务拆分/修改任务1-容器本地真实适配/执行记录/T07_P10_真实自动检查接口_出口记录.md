## 结果与问题

```text
正常路径结果：FakeRuntime 保持原语义；DOCKER_LOCAL 路由到 DockerLocalAutoCheckExecutor，复制冻结执行规则并返回 judge 结果；审核详情展示规则 digest、状态、尝试次数、摘要和 trace。
越权路径结果：跨模板版本或未扫描隐藏测试资产被拒绝；任意 shell/非 Python 命令被拒绝；学生不能修改自动检查规则、测试命令或隐藏测试资产。
状态冲突结果：QUEUED/RUNNING 自动检查时 decide 返回 AUTO_CHECK_PENDING；终态后教师可人工评分、评语、通过或退回；已决定审核仍保持只追加约束。
资源限制结果：judge 请求使用规则与任务冻结资源的较小值；TIMEOUT、RESOURCE_EXCEEDED、REJECTED 均落库并停止前端轮询；真实 cgroup 和容器限制留待 T10。
回收和对账结果：T07 不销毁 judge 容器、卷或对象；生命周期和孤儿回收属于 T08/T10；AutoCheckRun/ObjectAsset 使用 PROTECT/不可变事实约束。
日志、trace 和指标结果：自动检查完成事件包含 review、task、run、status、trace；证据仅保存 digest/摘要，不保存完整源码、隐藏测试正文或输出原文。
敏感信息泄漏检查：测试通过；错误 detail 仅保存异常类型和稳定错误码；响应不返回 Docker socket、对象 key、下载 token 或隐藏测试内容。

未解决阻塞：无代码阻塞；真实本地 Docker judge、容器网络/资源隔离、TTL 销毁和生产 Swarm 门禁待 T10/T11。
```
