**实际发现的问题**

1. 学生任务详情错误显示评审提示。Python 编程入门的“整数求和：从输入到输出”，任务 ID `01M6QE65B6GHA6XRY39NSMT5RH`，任务接口返回 `status=IN_PROGRESS`、`row_version=4`；教师页也显示“未提交”。评审结果接口返回 404 / `RESOURCE_NOT_FOUND`，但学生页仍显示“教师正在评审，评分与批注将在评审完成后显示。”这是展示不一致，不表示任务状态已经变成评审中。截图：`agent2-student-task.png`。
2. 管理端“服务与资源”显示“运行时引擎不可用，请按 trace 查询失败任务”。`/api/v2/platform/operations/overview` 返回 HTTP 200，但 alerts 包含 `severity=P1`、`code=RUNTIME_ENGINE_UNAVAILABLE`。本轮未启动工作区或运行代码，尚不能确认此告警对具体实验执行的影响。截图：`agent2-admin-resources.png`。

**浏览器入口问题与设置恢复**

此前 IP 地址被浏览器自动从 HTTP 升级为 HTTPS，导致 `ERR_BLOCKED_BY_CLIENT`。本次确认 ego lite 的“一律使用安全连接”为开启状态，临时关闭该选项后，用户指定的三个 HTTP 入口正常使用。验收后已恢复为开启；三类验收账号均已退出，任务空间已关闭。

先前尝试的 `student.edutech-lab.top`、`teacher.edutech-lab.top`、`platform.edutech-lab.top` HTTPS 页面能打开，版本同为目标 SHA，但登录被 403 / `CSRF_FAILED` 拒绝。读取线上生效设置并用正确 token 做独立 CSRF 校验，确认 HTTPS 域名缺少于可信来源列表，而对应 HTTP 来源通过。该诊断没有调用业务写入接口。未修改服务器配置；此问题独立于本次已通过的 HTTP IP 登录验收。
