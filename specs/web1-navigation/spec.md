# 三端导航与配色 Spec

## 背景与目标
学生、教师、管理门户导航行为和外壳配色不一致。本次以学生端现有浅灰绿色为准，保留业务页面结构。

## 功能需求
- F1：三端个人信息固定在侧栏底部；菜单较长时仅导航区滚动。
- F2：三端折叠后保留品牌图标，点击图标展开；折叠时不显示独立展开箭头，展开时保留收起按钮。
- F3：教师、管理端采用学生端同色导航和页面背景，内容面板为白色。
- F4：教师端显示教学云实验平台名称及图标，支持折叠和状态记忆；折叠导航仍可识别并访问各入口。

## 非功能需求
- 键盘可操作，按钮有可访问名称与展开状态；保留移动端现有导航适配。
- 三端分别存储折叠状态；保持路由、通知、个人菜单与退出功能。

## 范围
覆盖共享外壳、教师入口、管理主控制台及旧路由外壳；不改业务数据接口和内容布局。

## 验收标准
- AC1（F1）：长菜单下个人信息仍位于侧栏底部。
- AC2（F2）：收起后只通过品牌图标展开，无独立展开箭头，刷新保留状态。
- AC3（F3）：三端背景与导航同色；教师、管理内容面板白色。
- AC4（F4）：教师品牌图标与导航入口折叠后可用；键盘可展开。

## 执行授权
用户明确要求生成文件后直接实现，无需逐阶段审批。
