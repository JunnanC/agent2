# 三端导航与配色 Plan

## 架构
共享 AppShell 负责学生、教师和管理旧路由；管理主控制台沿用独立布局。两处使用同款 layers 品牌图标和同一交互约定。

## 状态与接口
继续使用 AppShell 的 collapsible、collapseStorageKey；教师及管理旧路由开启侧栏折叠。管理控制台使用 edu.admin.sidebar-collapsed 记录状态。localStorage 不可用时仍可操作。

## 模块设计
- AppShell：折叠时品牌标记变为展开按钮，移除独立展开按钮；底部个人菜单与可滚动导航分离。
- 共享样式：抽取与学生外壳一致的布局、浅灰绿色背景及白色内容面板；教师复用，不引入新 UI 库。
- 教师 guards：配置有图标导航、侧栏及通知折叠显示。
- 管理控制台：品牌按钮、收起按钮、导航滚动区和固定底部个人信息；兼容移动抽屉。

## 技术决策
保留原字体、配色语义和业务布局。本次为局部组件调整，按设计 skill 跳过重新抽取风格，以学生端现有色值为基准。桌面折叠规则在现有断点之上生效。
